# 4. Code smells

Líneas referidas a la revisión inicial `v1-inicial`.

## 1. Código duplicado

`app/orders.py`, `OrderService.save` (líneas 52-64) y `OrderService.quote` (líneas 103-116).

```python
if customer["category"] == "premium":
    discount = subtotal * 10 // 100
elif customer["category"] == "business":
    discount = subtotal * 15 // 100
else:
    discount = 0
if shipping == "pickup":
    delivery = 0
elif shipping == "standard":
    delivery = 0 if subtotal >= 10_000 else 1_000
else:
    delivery = 2_500
```

El mismo cálculo de descuento y envío está copiado en los dos métodos. Si cambia una regla, por ejemplo el umbral de envío gratis, hay que modificar ambos; si se olvida uno, la cotización deja de coincidir con el pedido guardado.

## 2. Método largo

`app/orders.py`, `OrderService.save` (líneas 33-90).

```python

    with self.database.connect() as connection:
        if order_id is not None:
            old = connection.execute("SELECT * FROM orders WHERE id = ?", (order_id,)).fetchone()
            ...
        customer = connection.execute("SELECT * FROM customers WHERE id = ?", (customer_id,)).fetchone()
        ...
        connection.executemany("INSERT INTO order_items(...) VALUES (?, ?, ?, ?)", ...)
```

En casi 60 líneas mezcla la verificación de estado, la búsqueda de cliente y productos, el cálculo de precios, la creación, la actualización y la lectura del resultado. Agregar una regla nueva, como un cupón de descuento, obliga a entender y tocar todo el método, y no se puede probar el cálculo sin base de datos.

## 3. Lista larga de parámetros

`app/orders.py`, firma de `save` (línea 33) y sus llamadas en `create_order` (líneas 195-197) y `update_order` (líneas 212-214).

```python
def save(self, customer_id, address, city, postal_code, shipping, items, order_id=None):

OrderService(request.app.state.database).save(
    data.customer_id, data.address, data.city, data.postal_code, data.shipping, data.items, order_id,
)
```

Se desarma `OrderInput` campo por campo para volver a pasarlo. Si se agrega un campo al pedido, como una referencia de entrega, hay que cambiar el modelo, la firma y las dos llamadas, y es fácil confundir el orden de `address`, `city` y `postal_code`. Además, `order_id=None` actúa como parámetro de control: decide si el método crea o actualiza.
